The third beta of version 2.0. Changes since Beta 2:

### Fixed

- **Nest on the bed by outlines** spread the parts down the bed's left edge,
  far apart. Now a sheet's parts are packed again across and stand together
  in its upper left corner. A sheet takes about 1.5 times the search time set
  (the progress bar counts it).
- **Running from source** (`start_kerfly.sh`, `start_kerfly.bat`): optional
  libraries added in an update are installed at the next start too. Whoever
  updated a Beta 1 folder had no spyrrow library and Nest by outlines greyed
  out.

### Changed

- The betas' AppImage is built and published by GitHub on its own (after the
  package's self-test and release test).

Full list of the 2.0 changes: [CHANGELOG.md](https://github.com/cyryllo/Kerfly/blob/2.0b3/CHANGELOG.md).
