# Polityka prywatności

Kerfly to program działający na Twoim komputerze. Nie ma konta, reklam ani
telemetrii: nie zbiera, nie przechowuje i nie wysyła danych o Tobie ani o
Twojej pracy.

## Co Kerfly wysyła przez sieć

- **Nowe wersje.** Raz dziennie, przy uruchomieniu, Kerfly pyta GitHuba o
  najnowsze wydanie (`api.github.com/repos/cyryllo/Kerfly/releases/latest`).
  Zapytanie zawiera wersję Kerfly (w nagłówku User-Agent, np.
  `Kerfly/1.8.1 (update check)`) i nic o Tobie, Twoim komputerze ani projektach.
  Jak przy każdym zapytaniu w sieci, GitHub widzi Twój adres IP; obowiązuje
  [polityka prywatności GitHuba](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
  Można to wyłączyć w **Ustawienia → Zaawansowane → Sprawdzaj raz dziennie
  nową wersję**. **Pomoc → Sprawdź aktualizacje** pyta tylko po kliknięciu.
- **Nic więcej** nie wychodzi samo. **Pomoc → Zgłoś problem na GitHubie…**
  zapisuje raport diagnostyczny na Twoim komputerze i otwiera w przeglądarce
  formularz zgłoszenia na GitHubie (z wersją Kerfly, systemem i płytą w
  adresie); nic nie jest wysyłane, dopóki sam nie wypełnisz i nie wyślesz
  formularza z raportem.

## Co Kerfly przechowuje na Twoim komputerze

Ustawienia, bazę materiałów, profile laserów, dziennik diagnostyczny i
obrazki, które tworzy (pieczątki, wycięte fragmenty obrazków), w folderze
ustawień Twojego użytkownika. Projekty zapisują się tam, gdzie wybierzesz.
Nic z tego nie opuszcza komputera, dopóki sam tego nie wyślesz.
